# Provenance — PHP 7.2.34

This community repository redistributes Sury's PHP 7.2.34 source backport
without modifying the patch bytes. Coolestcool is the repository maintainer
and claims no authorship of the original fix or version-specific backport.
This is not an official Sury project or a GitHub fork of its packaging history.

Only the PHP 7.2.34 files appear in the current tree. See
[provenance.json](provenance.json) for exact vendor archive URLs, source-package
revisions, member paths, SHA-256 values and byte-comparison results.

The main patch headers credit Arnaud Le Blanc and Ilija Tovilo. PHP Group, Zend
contributors and Sury maintainers retain their respective credits and licenses.
The PHP 7.2 ZSTR_MAX_LEN prerequisite, where distributed, credits Remi Collet
and identifies upstream commit 37056ad634d9c44bac0d6c8e730eafaec1344840.

These are minimal EOL backports. They must not be described as the complete
maintained-branch implementation or a comprehensive legacy security update.

Preserve notices when redistributing source or binaries. Supporting repository
materials have the separate MIT terms described in LICENSE.
